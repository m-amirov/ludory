# Opt-in narrative economy starter

This is a **new-game example, not a payment-ready game**. The default `config/economy.json` has `enabled:false`, zero registered Yandex SKUs, and never calls an economy SDK or credits currency. The optional premium story path is playable for free until you deliberately enable the sidecar and cloud wallet. The first shipped game «Поцелуй на краю света» must stay disabled unless its owner explicitly decides otherwise.

## Author setup (new games only)

1. Edit author-owned `src/story.js`, `config/premium.json` and `config/economy.json` for your own graph, optional choices, safe free good-ending traces, pricing and grants. The economy `gameId` is always derived from `ludory.project.json`; do not manually reuse another game's wallet namespace.
2. Configure the platform SDK bootstrap in `src/entry.js` **before** enabling economy. Supply `economyPorts: {storage, narrativeStorage, ads?, purchases?}`. Import `createYandexEconomyStorage({config,getPlayer})` with `createYandexPlayerStorage({getPlayer,namespace:gameId})`, or `createVkEconomyStorage({config,bridge})` with `createVkStorage({bridge,namespace:gameId})`, from `assets/ludory-economy.js`. The first factory is `storage` (independent wallet record); the second is `narrativeStorage` (Runtime story snapshot). These factories require actual, initialized platform SDK handles; they do not initialize the SDK, select an account or grant purchases. Use the same game-specific namespace, respecting VK's stricter length limit. Do not use localStorage for monetized progress.
3. Set `enabled:true` only after the cloud and verified SDK ports are available. Call `startEconomyNarrative({ target:'yandex-games'|'vk-games', economyPorts })` with the explicit active target. The example source binds the validated premium manifest to the exact graph and ensures a free good ending.
4. To add real Yandex consumable offers, configure immutable product SKU mappings, register products in the Yandex Console, add a valid `createYandexPurchases` port and call `startEconomyNarrative({ ..., storeEnabled:true, activeSkus:['your_sku'] })`. Use the SDK catalog price and portal currency; never hardcode real-money prices. The coordinator restores outstanding purchases before unlocking premium choices. VK IAP is **not** supported.
5. For rewarded ads, inject the platform's verified rewarded adapter. Ad success must be observed by that adapter and durably saved before acknowledging a reward. There are no interstitial ads inside story choices.

The sample values (20 starter crystals, 3 per episode, 2 daily, 5 for a voluntary rewarded ad, 12 for the extra scene) illustrate the mechanic; **they are not a recommended production economy**. Starter and episode grants must be triggered by explicit author-controlled events, not silently on startup.

This sample does not prove real Yandex/VK purchase, cross-device, ad, moderation or policy compliance. The serverless model cannot guarantee fraud resistance or cross-device transactional updates. Run simulated QA and the real platform gates separately before any monetized release. No publication is authorized by this template.

Studio browser preview intentionally distributes **only** `config/economy.json` and `config/premium.json` from the `config/` directory. Both must contain public, non-secret author settings. Other private config files are never copied. A corrupt/incompatible narrative save is left untouched and blocks saving until the player explicitly uses **Начать заново**; this resets narrative progress only, not wallet/entitlements. If a cloud adapter cannot clear safely, the UI blocks automatic recovery rather than deleting or overwriting data.
